# stock-landing

간단한 주식 서비스 랜딩 페이지 예제예요. 가상의 서비스 **StockLens**를 소개하는 단일 HTML 페이지로, 별도 빌드 없이 바로 열어볼 수 있어요.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 랜딩 페이지 본문 (HTML + CSS 한 파일) |
| `README.md` | 이 폴더에 대한 설명 |

## 페이지 섹션

- **히어로**: 서비스 소개 문구와 시작하기 버튼
- **오늘의 시장**: KOSPI, KOSDAQ, S&P 500, USD/KRW 카드 (예시 데이터)
- **주요 기능**: 관심 종목, 가격 알림, 포트폴리오 분석
- **CTA**: 출시 알림 받기

## 실행 방법

`index.html`을 브라우저로 열면 돼요.

## 참고

- 페이지의 시세는 모두 **예시 데이터**이며 실제 시장 정보나 투자 권유가 아니에요.
- 하단의 연락처(`hello@example.com`)는 자리표시용이에요.
